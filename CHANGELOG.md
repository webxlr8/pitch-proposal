# Changelog

## 0.1.0 · 2026-10-14
First release.
- `profile_from_site.py`: sender profile (logo, colours, fonts, contact, social, services) from a website; same format as pitch-audit.
- `crawl_site.py`: sitemap or link crawl; menu, pages, forms and fields, embeds, shop/checkout/donation/booking signals, broken links, tech stack.
- `screenshots.py`: desktop and mobile screenshots with installed Chrome; crops and contact sheets.
- `stock_photos.py`: free Unsplash / Pexels photos with credits; refuses Unsplash+.
- `new_proposal.py`: presets `build`, `refresh`, `plan`; 15 A4 page templates; dark and light themes from the profile.
- `build.py`: Chrome PDF, page previews, checks (overflow, tokens, placeholders, prices, banned words, template text, empty space).
- Two examples: a new platform (dark) and a website refresh (light, fully fictional).
